# Agent Note: 统一账户币种并补齐账本恢复边界

Status: implemented

## Problem

外币账户的期初余额与流水增量使用了不同币种。自身 CSV 导回会丢失转账语义，账本 JSON 只有导出，整库 JSON 只记录附件路径。软删除流水立即删除凭证、标签关系与分账。只读成员会看到部分写操作，也无法打开订阅历史。

## Decision

- 流水保存两端的账户原币金额。账户余额和信用额度使用原币。收支报表使用入账折算金额，净资产以当前汇率估值。记账、校准、删除和恢复在 D1 批次内变更流水及余额。已存在流水的站点本位币和账户币种保持固定。
- 净资产历史月份以账户创建日和期初快照为起点，回放余额流水时排除冻结导入（`source = 'kap-import'`），因为这些流水未变动账户实存余额。当前月采用计入净资产的活跃账户实存余额。冻结流水仍参与分类、收支趋势和成员统计。年末快照的实存余额口径见[年度账本结转](../feature/2026-11-25-annual-ledger-rollover.md)。
- HomeLedger CSV 识别独立表头，预览严格匹配账户名和分类路径，按原币、折算金额与账户侧金额写入。单账本 JSON 导入新账本，重建流水、分账、标签与规划项目关联。新账本由导入者持有，自动记账需重新启用。
- 整站运维归档包含 D1 快照及已引用的 R2 凭证和头像。命令核验 SHA-256、上传至本次恢复独享的对象键并读回核验。服务端核对绑定桶中的本批次键并在 D1 批次内提交数据、余额重算和会话及令牌吊销。
- 软删除保留标签、分账和已关联凭证。存档、Web 和 OpenAPI 的附件入口隐藏回收站对象，永久删除按已知键清理。R2 删除失败后回收站保留待完成状态，可重试永久删除。
- 页面根据账本角色展示写操作。只读成员可查看订阅扣费历史，提交同一订阅的写请求仍经过服务端权限校验。

- 编辑页将旧账户侧金额作为提示。金额、币种、汇率或对应账户变更时，按本次明确输入或有效汇率更新其账户侧金额。仅编辑附加信息时保留已记金额。
- 迁移和整库恢复沿用实时余额语义，缺少对侧账户的历史投资卖出不产生余额变动。单账本复制和永久删除同步处理次卡的购卡流水引用。
- CSV 复用交易类型的账户及分类规则。第三方账单按导入请求批量读取账户币种及汇率，逐行金额计算在内存完成。

## Alternatives considered

- 用本位币统一账户余额可减少流水字段，但用户无法直接拿外币账户余额与银行账单核对，信用额度也会混用币种。
- 将附件全部内嵌到网页 JSON 可以直接下载单文件，但会把图片大小和批量搬迁压力转移到 Worker 请求，整站文件交由运维归档处理。
- 软删时直接清理 R2 节省存储，代价是误删无法还原凭证。保留至主动永久删除可以利用现有数据库关联隐藏文件。
- 继续预填旧原币值能让用户直接修改数字，但浏览器会把未修改值作为输入提交。用提示展示原值，服务端可区分明确输入与留空，并可接受一次有意输入的相同金额。
- 逐笔读取账户和汇率能拿到最新值，但同一批账单可能混用不同时间点的汇率，也会消耗每次调用的 D1 查询额度。批次使用一次读取的汇率，自动创建的账户更新本次导入的账户列表。
- 将全部历史流水纳入净资产回放能统一取数条件，但冻结导入会让尚未创建的账户出现虚假余额。净资产回放单独按来源过滤。

## Consequences

- 转账的两端余额可以分别核对，改汇率无需重写旧流水。迁移按原交易币种和保存的折算金额还原可确定的旧数据。历史第三币种的增量暂不计入对应账户余额，并在账户详情给出编辑入口。迁移前曾更换站点本位币的账本需要额外核对历史折算金额。
- D1 与 R2 没有共享事务。备份在暂停写入的维护窗口执行，恢复失败或替换留下的孤儿 R2 对象由管理员手动清理。整站归档的 D1 JSON 部分继承 20MB 恢复上限，单账本复制不搬运 R2 文件。
- 软删期间账户及分类引用仍有效，清理实体前需先处理回收站中的引用。报销入账保留原有结算约束，删除后从原支出重新报销。

## Verification

- 本地测试覆盖原币迁移精确回填与待校准项、跨币种转账编辑和复算、软删恢复标签与分账、凭证隐藏和失败后继续永久删除。
- HomeLedger CSV 测试覆盖缺失账户行级错误、重复导入和两端金额，单账本复制测试覆盖新账户与分账关联。
- 归档测试覆盖目标桶缺对象时保留现存数据。独立 Wrangler 本地 D1/R2 实测归档成功恢复凭证、头像和外币余额。
- 只读成员可读取订阅历史，直接打开编辑页或提交扣费操作返回 403。
- Web 与 OpenAPI 报表回归核对账户创建前的净资产、当前月净资产、历史分类和收支及成员数据，并检查生成报表前后账户实存余额一致。
- 回归覆盖 Web 编辑金额后余额变化、显式账户侧输入和仅改备注、迁移与重算的历史卖出口径、次卡购卡引用重映射和清理，以及第三方 60 行账单的 D1 读取次数。
